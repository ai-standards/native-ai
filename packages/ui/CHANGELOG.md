# Change Log

## [0.1.0] - 2025-01-10

### Added
- Initial release of @nativeai/ui
- Core components: Button, Input, Card
- Layout system with VS Code-inspired design
- Comprehensive icon library using Lucide icons
- TypeScript support with full type definitions
- Tailwind CSS integration
- Storybook documentation
- Vitest testing setup

### Components
- **Button** - Multiple variants and sizes
- **Input** - Form input with validation states  
- **Card** - Flexible content containers
- **Layout** - Complete VS Code-like layout system
- **Icons** - 35+ Lucide-based icons

### Features
- Slot projection for Layout components
- Dark/light theme support
- Responsive design patterns
- Tree-shakeable exports
- Comprehensive documentation
