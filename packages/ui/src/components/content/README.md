# Content Components

Foundational components for rendering and structuring content. These elements provide consistent typography, spacing, and presentation patterns across the application. Each component includes TypeScript support, accessibility features, and Storybook examples.

### Typography
Comprehensive text and heading components for rendering semantic, accessible, and theme-consistent text content.

**Features:** Headings and paragraphs, text variants (body, caption, label), semantic tags, responsive sizing, color and weight props  
**Documentation:** [Typography README](./typography/README.md)

### Divider
Horizontal and vertical divider component for visually separating content sections and establishing layout rhythm.

**Features:** Horizontal/vertical orientation, dashed/solid styles, color variants, spacing controls  
**Documentation:** [Divider README](./divider/README.md)

### Section
Structural container for grouping related content with optional padding, background, and layout variants.

**Features:** Size and spacing variants, background options, responsive behavior, content alignment utilities  
**Documentation:** [Section README](./section/README.md)

### Code
Inline and block code display with syntax highlighting and monospaced typography.

**Features:** Inline and block modes, syntax highlighting, line wrapping options, copy-to-clipboard support  
**Documentation:** [Code README](./code/README.md)

### Quote
Blockquote component for displaying quotations, callouts, or highlighted text with elegant styling.

**Features:** Styled quotation marks, alignment options, citation support, typographic scaling  
**Documentation:** [Quote README](./quote/README.md)

### List
Semantic list component with support for ordered, unordered, and custom marker styles.

**Features:** Ordered/unordered lists, nested lists, marker variants (disc, decimal, custom), spacing and alignment control  
**Documentation:** [List README](./list/README.md)

Future content components planned for development. These will follow the same design principles and patterns as the current components.

### Table
Semantic, responsive table component with optional headers, captions, and scroll support.

**Features:** Responsive layout, sticky headers, compact and spacious variants, zebra striping, sorting hooks  
**Documentation:** [Table README](./table/README.md)

### Callout
Emphasized content block for displaying key messages, alerts, or feature highlights.

**Features:** Visual variants, icon support, accent colors, dismissible behavior, size options  
**Documentation:** [Callout README](./callout/README.md)

---

## Design Principles

- **Semantic by Default** – Accessible HTML structure and ARIA support for content clarity.  
- **Consistent Typography** – Unified typographic scale and spacing system across all content.  
- **Composable Layouts** – Content components work together seamlessly in any surface or container.  
- **Theme Friendly** – Full support for light/dark modes and custom themes.  
- **Responsive Design** – Content adapts gracefully to different viewports and breakpoints.
